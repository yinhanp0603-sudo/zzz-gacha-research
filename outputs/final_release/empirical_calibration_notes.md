# 两个旋钮的实证锚点

统计对象为已提交且合格的完整三人通关记录。主表按原始战斗粒度统计，同一玩家可有多场战斗；跨采集快照不合并身份。未通关、未持有和未提交记录不可见。

## 机制锁

Boss 维表保留 `mech_regime` 五个历史时期字段，新增 `empirical_mech_regime` 细分机制类别、`mech_desc` 和 `favored_group`。实证表的 `mech_regime` 使用细分机制类别。对策组在读取成绩前登记，按主核职业、点名体系组件及三异常条件判定；泛用击破不独立定义主核。以太帷幕类的主核代理只覆盖当前登记的帷幕主核能力，不等于战斗内完整技能触发检测。

`HHI` 对互斥的核心机制组合签名求份额平方和，多核队不被强行分给一个主 C。`HHI_core_signature` 使用更细的角色主核签名。对策覆盖、混合主核比例和 HHI 的定义分别保留。`off_meta_score_ratio` 是非对策组中位分／对策组中位分；`score_comparison_design` 区分原始组间比较和同房间、同采集快照、主核影画／专武档位／等级相同的单核子组。后者仍不是同一角色、同一全队配置。

`empirical_knob1_lambda_reference.csv` 只代数计算冻结参数下的五档 λ 输出保留率，不运行战斗仿真。0.4 与 1.0 是明确标注的盾覆盖参考情景。真实分数既非直接 DPS 也非清除指数，缺少输出分布、失败队伍与 Boss 实际暴露时长，不能把分数比反解为唯一 λ。

## 专属体系组件

分层固定采集快照、赛季、模式、房间、主 C 影画、实际装备名称、60级、盘套装组合与已记录的潜能。`fixed_third_matched` 额外固定第三名队友身份，并要求目标与替代位具有相同职业；`main_build_matched` 比较主 C 配装相同但其他队友可不同的组件组合。对照不含指定组件，并至少有一个预登记旧替代位。替代位可为 A／常驻 S／免费 S，或早于目标组件上线的支援／副输出。无法据此认定全队同金数。

同一层内用中位分相除，或用无组件用时／有组件用时，得到 `median_score_ratio`、`speed_ratio`。每组至少20条记录的分层标为可稳定描述；低样本分层仍完整保留。汇总对层内比值按两组样本数的调和重叠权重求几何均值，没有把分层中位数平均成总样本中位数。汇总参与次数可重叠，不当作独立玩家人数。`n_shared_players` 显示是否确有同一玩家两种配队；分层匹配不能冒充随机配对实验。

专武状态来自实际装备名称，缺失武器不当作0+0；其他已知武器为未装备本命专武，可能仍是其他限定 S 武器。数据没有盘词条、武器等级／叠影、技能等级、完整投入成本与操作水平，装备快照也未必等于战斗瞬间配置。式舆后期为得分制，不将分数倒算通关速度。出现赛季数是样本覆盖，不能称作延寿或玩家存活。

观测倍率可为参数范围提供条件性成绩锚点，但不等于因果支援倍率。对照组的旧辅助也能提供增益，不同于模型中的无增益中性位，不能把新旧辅助间的成绩比直接当作新增支援的绝对倍率。模型中总支援倍率为1+a×g，a并非总输出倍率：g=0.35时，a∈[0.8,1.6]对应1.28–1.56倍；g=0.45时对应1.36–1.72倍。两张主表不伪造唯一 λ／a 估计，未改变模型参数。
