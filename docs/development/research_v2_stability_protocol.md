# 机制锁与售后支援：跨种子配对复核协议

目标是在同一战斗和付费模型下，判断 25 个候选的现金与留存差异有多大、种子间波动有多宽，以及哪些差异仍需扩大人口才能分辨。

## 实验范围

| 项目 | 本轮设定 |
|---|---|
| 科学配置 | `config/research_v2/experiment.json`，沿用 v2 公式与参数 |
| 物理运行 | 25 个 P0 候选 × 8 个种子，每次 20 期；人口分别运行 N=200 与 N=1000 |
| 筛选种子 | 1101、1102、1103、1104、1105 |
| 独立复核种子 | 9101、9102、9103 |
| 观察窗口 | 同一个 20 期数据库的第 10 期和第 20 期 |
| 模块消融与痛感扰动 | 使用独立的中等规模预算，主网格单独扩样 |
| 新产物 | `outputs/research_v2_stability/` 与 `outputs/research_v2_stability_n1000/` |

同一种子内，25 个候选共用初始人群与事件索引公共随机数。人群、抽卡、消费和流失的随机事件都由种子与事件键确定。增加种子会增加独立重复，不改变既有种子的随机结果和科学配置身份。

N=200 实验复用已有 1101、9101 的 50 个主网格 20 期数据库，新增其余 150 次运行。N=1000 使用独立目录与科学配置身份，不复用人口不一致的运行结果。汇总日志保留现金、资源、生命周期和消费意愿；原有全量日志继续保存老角色面板。10 期结果只截取前缀，不再多做一套物理模拟。

10 期和 20 期来自同一次运行，不能当作两个独立种子。已验证前 10 期的状态转移不受观察窗末端影响；比较短长期时使用相同商品目录的前缀。

## 现金分拆与固定分母

总现金由三类互斥现金相加，均以元记账：

- 新主 C 直购：主输出商品对应的本体、影画和专武目标所触发的即时充值。
- 专拐直购：支援商品池所触发的即时充值。
- 月卡续订：实际续购订阅权益时产生的现金。

本轮目录每期恰好一个商品，按当期商品类型归属直购现金。抽取来源仍保留当期免费、历史免费、订阅权益和直购四类；免费抽数和已购权益的消耗不记作新增现金。

总体留存分母为初始玩家总数。核心留存分母为该种子的初始 `Budget_40` 人数，停氪但仍活跃者继续留在分母并计为留存。`Budget_160` 与 `Budget_500` 的合计期望人数在 N=200 时为 40、N=1000 时为 200，实际值按种子列出，不能把期望人数写成每组实际人数。

跨种子汇总先计算每个种子的固定分母留存率，再按种子等权平均；配对差的误差估计也以种子为独立单位。

同一种子内预算层构成完全相同，候选之间的配对差可控制这一来源的波动。跨种子的误差仍包含人群构成、抽卡、消费意愿和流失随机性。

## 现金变化的可加拆解

a 轴对照先在同一种子内对五档 λ 等权平均。设该种子 a 低档的总现金为 Bₛ，三类现金 k 的高低档差为 ΔCₖ,ₛ，则贡献定义为：

\[
q_{k,s}=100\frac{\Delta C_{k,s}}{B_s},\qquad
\sum_kq_{k,s}=100\frac{\Delta C_{total,s}}{B_s}.
\]

三个分项使用同一个基期总现金分母，贡献的单位为百分点；不是各分项各自的增长率。金额差与贡献均先逐种子计算，再求均值、标准误和 t95 区间。其均值保持可加，区间端点不相加。

绝对金额差的估计对各种子的金额差等权平均，归一化贡献则先除以各种子的基期总现金，再等权平均。两个估计量的区间是否跨零可能不同，分项方向按相应口径解释。

总现金区间由每个种子的三项现金变化求和后独立估计，保留分项协方差。主 C 池、专拐池与订阅现金的正负方向按实际配对结果报告；点估计抵消与分项方向已经稳定识别分别表述。全部端点和相邻档位输出 `axis_cash_decomposition.csv`，每个种子的金额、共同分母和贡献保存在 `cash_decomposition_seed.csv`。

## 排序与配对误差

每个观察窗分别报告总现金、三类现金、核心留存和总体留存的 Spearman ρ。ρ 比较 25 个候选的筛选种子均值与独立复核种子均值。分项排序可能更稳，也可能更弱；若候选均值为常数，相关系数未定义。

扩样前后的排名对照使用当前数据中固定的 1+1 种子子样本：配置中的首个筛选种子 1101 与首个复核种子 9101。子样本与完整 5+3 组的 N、模型和候选相同。两组共享种子，ρ 的变化是描述性对照，不当作相互独立的显著性检验；人口扩大后也保留相同的种子子样本定义。

人口从 N=200 扩至 N=1000 的主排序对照使用两种规模各自完整的 5+3 组，并保持筛选、复核种子名单一致。报告开头展示两个观察窗的总现金 ρ，第 1 节按现金结构与留存逐项比较；同 N 的 1+1 子样本另列。先确认基准模型的人口覆盖项以外配置身份一致，再读取 N200 对照；结果保存在 `population_rank_comparison.csv`。两种人口规模共享种子和前段玩家，排序差异同样属于描述性比较。

候选比较以种子为独立单位。对候选 j 与基准 b，在种子 s 内计算：

\[
\delta_s = Y_{j,s} - Y_{b,s},\qquad
\bar\delta = \frac{1}{n}\sum_s\delta_s,\qquad
SE(\bar\delta)=\frac{SD(\delta_s)}{\sqrt n}.
\]

近似 95% 区间采用自由度 `n−1` 的 Student-t 临界值；种子数很少时其覆盖依赖种子差值分布的近似。现金差同时保留元与种子内相对百分比；留存差使用百分点。相对百分比先逐种子计算，再求其均值和区间，不用两个组均值相除替代配对相对变化。

基准候选固定为 `λ=1,a=1`。同时保留全部候选两两比较，便于判断接近的候选是否仍难区分。全量区间都是逐项 95% 区间，不具有整组同时覆盖保证，不据此宣布统计上确定的唯一最优策略。

λ 端点与相邻档位对照在同一种子内先等权平均五档 a，再计算高档减低档；a 对照同理。五档配置使用同一随机种子，不当作五个独立重复。

收入与核心留存分别作为目标。每个种子独立计算有限候选的非支配集合，再记录各候选入选次数；筛选/复核分开，种子均值上的非支配集合另列。三组复核的入选频率只有四档，描述本轮结果，不是最优策略概率。

人口扩样前指定 `λ=1,a=1.4` 与 `λ=1,a=1.6` 为关注候选。第 3 节同时展示它们在 N=200 与 N=1000 下的复核核心留存、人均现金、相对 `λ=1,a=1` 的人均现金差区间和前沿入选次数。选择名单不随结果改变；入选 3/3 仍不构成总体最优策略的证明。人均配对差将各人口规模的现金差和区间除以初始人数，避免直接以规模更大的绝对金额比较精度。

## 执行与扩样

查看主网格运行计划：

```powershell
.\.venv\Scripts\python.exe tools\run_research_v2_stability.py --plan-only
```

补齐 5 组筛选与 3 组复核种子：

```powershell
.\.venv\Scripts\python.exe tools\run_research_v2_stability.py --players 200 --workers 4
```

同配置已完成的运行直接复用。扩大人口时写入独立目录，主网格与消融/心理扰动保持非对称规模：

```powershell
.\.venv\Scripts\python.exe tools\run_research_v2_stability.py --players 1000 --workers 4 --out outputs\research_v2_stability_n1000
```

人口从 200 增至 1000 或 3000 会形成新的科学配置身份，已有种子的前 200 个玩家保留各自的事件键。增人口的价值依据配对标准误、相近候选区间和独立复核的排序变化判断；不把收入极差变大或 ρ 必须超过某值设为标定目标。

独立多项抽样下，预算层初始比例的标准差约按 1/√N 缩放，绝对人数的标准差则随 √N 增长。玩家相互独立、个体分布稳定且配对现金差方差有限时，人均现金配对标准误理论上按 1/√N 缩放，总现金差的绝对元标准误按 √N 增长；个体内部的保底、消费与流失非线性本身不破坏这一结论。实际区间宽度由仅三组复核种子估计，仍有抽样波动；相对现金变化的基期分母也随种子随机变化，实际宽度比不必恰好等于理论缩放比。种子数保持三组时，t 区间自由度仍为 2，参数设定的不确定性也不随人口扩样而消除。

N=200 与 N=1000 的精度比较优先采用现金相对变化的区间宽度，或将现金差与区间除以初始人数后比较。绝对元区间可能随业务规模扩大而变宽，不能据此直接判断精度下降。人数表本身也不能识别人群构成对配对方差的贡献；其影响与抽卡、消费和流失随机性共同体现在种子差值中。

## 适用范围

本轮置信区间描述指定情景模型下的随机误差，行为与战斗参数的不确定性属于单独的敏感性分析。公开通关记录提供条件成绩参照，不识别付费心理或官方机制参数的因果值。

模型规划当前卡池的部分获取结果，不预知未来排期或求解跨期最优囤抽。固定初始队列不含获客、回流和运营成本；累计现金用于情景比较，不是游戏全盘流水或完整 LTV。
